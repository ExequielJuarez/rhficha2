FICHA TECNICA DE VEHICULOS - VERSION PORTABLE
=============================================

NO HAY QUE INSTALAR NADA (ni Node.js ni MySQL). Esta carpeta ya trae todo lo necesario.

PRIMER USO
  1. Copie esta carpeta completa al disco C: (por ejemplo C:\FichaTecnica). No la use desde el pendrive
     ni desde el Escritorio de OneDrive.
  2. Haga doble clic en  iniciar.bat
  3. La primera vez tarda un minuto en preparar la base de datos.
  4. Si Windows pregunta por el Firewall, elija "Permitir acceso" (redes privadas). Es necesario para
     usar el sistema desde otra PC o celular.
  5. Se abre el navegador. Ingrese con uno de estos usuarios:
        admin     clave: Ficha2026!     (ve TODO: reportes, auditoria, usuarios y roles)
        usuario   clave: Usuario2026!   (solo lo operativo; no ve reportes ni auditoria)
     Cambie las claves al entrar (Control de Acceso > Usuarios).
  6. El sistema arranca VACIO: cargue sus vehiculos y choferes.

USO DIARIO
  - Abrir:   doble clic en iniciar.bat (la ventana negra debe quedar abierta mientras se usa).
  - Cerrar:  al terminar haga doble clic en detener.bat. Guarda una copia de seguridad y apaga todo.
             (Si apaga la PC sin hacerlo, los datos no se pierden; solo no se genera la copia de ese dia.)

USAR DESDE OTRA PC O CELULAR
  - Deben estar conectados a la misma red que esta PC.
  - En el navegador escriba la direccion que aparece en la ventana negra, por ejemplo  http://192.168.1.20:3100
  - La PC debe estar encendida con el sistema abierto.

COPIAS DE SEGURIDAD
  - Se crean solas al usar detener.bat, en la carpeta "respaldos". Tambien con respaldo.bat.
  - IMPORTANTE: copie cada tanto las carpetas "respaldos" y "datos\archivos" (documentos subidos)
    y "app\public\img" (fotos subidas) a un pendrive o a la nube.
  - Para volver a una copia: arrastre el archivo .sql encima de restaurar.bat

EMPEZAR DE CERO
  - limpiar-datos.bat borra vehiculos, choferes y todo lo asociado (pide confirmacion). Conserva los usuarios.

PASAR EL SISTEMA A OTRA PC
  Cierre con detener.bat y copie la carpeta completa (o solo "datos", "respaldos" y "app\public\img" a una carpeta nueva).

PROBLEMAS FRECUENTES
  - La ventana negra se abre y se cierra sola / no pasa nada: ejecute iniciar.bat de nuevo; ahora la ventana queda abierta y muestra el
    motivo. Verifique que descomprimio TODA la carpeta (no abrirlo desde dentro del ZIP) y que no hay otro sistema usando el puerto 3100.
  - "VCRUNTIME140.dll no se encuentra": instale "Microsoft Visual C++ Redistributable 2015-2022 (x64)" desde la web de Microsoft.
  - El navegador dice "no se puede conectar": espere unos segundos y actualice la pagina; si sigue igual, cierre todo con
    detener.bat y abra de nuevo.
  - Otra PC no entra: revise que este en la misma red y que el Firewall haya permitido "node.exe".
